# 日志目录

本目录保存工程搭建与 benchmark 实现的过程记录，**非运行时依赖**。

| 文件 | 说明 |
|------|------|
| `folder-creation-*.log` | 初始五类文件夹创建 |
| `project-setup-*.log` | 30 benchmark 骨架生成 |
| `bert-batch-encoding-*.log` | 首个可运行 inference benchmark |
| `ai-inference-implementation-*.log` | ai-inference 六项实现 |
| `four-categories-implementation-*.log` | 其余四类 24 项实现 |

汇总性 markdown（`*-summary.md`）为人工可读摘要。

当前工程状态以根目录 [README.md](../README.md) 为准。
